# BROCHURE_RESTYLE_NOTES

Esta ronda se rehízo tomando como referencia los trípticos enviados por el cliente.

## Qué se corrigió
- Se abandonó la línea visual tipo fintech oscura / SaaS premium.
- La web ahora se orienta a un tono más institucional, corporativo y financiero tradicional.
- Se reforzó la paleta verde + naranja + blanco.
- Se separaron mejor las líneas:
  - Empresa
  - Consultoría / gerencia financiera tercerizada
  - Inversiones y financiamientos
  - Capacitación
